# 블로깅 프로젝트 작업 지시사항

## 검색 및 조사 극대화

**수치, 통계, 구체적 사실이 필요한 경우:**
- 추측이나 "~일 것 같습니다" 금지 절대금지
- 불확실하면 먼저 `WebSearch`, `WebFetch`로 조사
- 코드/DB/파일에서 직접 확인 가능한 것은 `Read`, `Bash` 등으로 검증
- "확인하고 돌아오겠습니다"로 응답 후 조사 수행

**예시:**
- 네이버 노출 통계, AI 랭킹 알고리즘 → WebSearch로 최신 정보 확인
- 프로젝트 내 구체적 수행률, 통계 → 코드/메모리 직접 확인
- API 정책, 플랫폼 변경 사항 → 공식 문서/공지 검색

근거 없는 수치는 신뢰도와 의사결정을 해칩니다.
